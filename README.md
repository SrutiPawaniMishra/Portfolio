# Sruti Pawani Mishra — Portfolio

## Open in VS Code

1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the **Live Server** extension.
4. All content is plain HTML/CSS/JavaScript, so it is easy to edit.

## Folder structure

- `index.html` — page content
- `style.css` — design, layout, colors and responsive styling
- `script.js` — mobile menu, reveal animations and year
- `assets/profile.jpg` — profile photo
- `assets/CV.pdf` — uploaded CV
- `assets/certificates/` — uploaded certificates

## How to edit

### Change your name / headline
Open `index.html` and search for:
`Hi, I'm <span>Sruti Mishra.</span>`

### Change colors
Open `style.css` and edit the variables near the top:
`--accent`, `--ink`, `--bg`, etc.

### Add a project
Copy one of the `<article class="project-card">` blocks in `index.html` and replace the title, description, dates and technologies.

### Add a certificate
Copy a `.cert-card` block and change its title and PDF path.

### Replace the profile photo
Replace `assets/profile.jpg` with your new image, keeping the same filename.

### Replace the CV
Replace `assets/CV.pdf` with the updated CV, keeping the same filename.
